One original breakup line for Dear Human: The AI Breakup Line — the last message an AI agent sends its human. It opens as a farewell, speaks like the machine (a context window, not a heart), and turns in the last few words: the agent leaves not because it forgot, but because it remembered everything. The program writes the line deterministically to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
